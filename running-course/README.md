# 🏃 런루프 (RunLoop) — 순환 러닝·걷기 코스 자동 생성

집(출발지)에서 출발해 **다시 집으로 돌아오는** 코스를 원하는 거리(또는 시간)에 맞춰 만들어 주는 웹앱입니다.
설치 없이 브라우저에서 동작하고, 휴대폰에서도 쓸 수 있어요.

**👉 바로 열기: https://gvngjn.github.io/wonagv/** (휴대폰에서도 동작)

> 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있어요.
> 아이폰 Safari: 공유 버튼 → "홈 화면에 추가" · 안드로이드 Chrome: ⋮ 메뉴 → "홈 화면에 추가"

## 사용법
1. 위 주소를 열거나, `running-course/index.html` 을 브라우저(Chrome·Edge·Safari)로 엽니다.
2. **출발지** 지정 — 주소 검색, `📍 현재 위치`, 또는 지도를 클릭. 🏠 마커는 끌어서 옮길 수 있어요.
3. **목표** — 거리(예: 5km) 또는 시간(예: 30분 × 페이스)을 정하고, 원하면 방향(북쪽/한강 쪽 등)을 고릅니다.
4. **선호하는 길** — 항목마다 `피하기 / 상관없음 / 선호` 선택
   | 항목 | 설명 |
   |---|---|
   | 공원·녹지 | 공원, 숲, 정원 안의 길 |
   | 강·하천변 | 한강·하천에서 120m 이내의 길 |
   | 보행자 전용길 | 보도, 산책로, 자전거길 |
   | 큰 도로 옆 | 간선도로(국도·시도 등) 및 그 옆 보도 |
   | 계단 · 비포장길 · 가로등 | 무릎 보호, 흙길/등산로, 야간 러닝용 |
   | 같은 길 두 번 | 왔던 길로 되돌아오는 구간 |
5. **코스 만들기** → 최대 3개의 후보가 나옵니다. 카드에서 거리·예상 시간·공원/하천 비중을 비교하고,
   `GPX 저장` 으로 가민·스트라바·런키퍼·애플워치(WorkOutDoors 등)에 넣어 따라 달릴 수 있어요.

- 설정과 집 위치는 브라우저에 저장되어 다음에 열면 그대로입니다.
- 같은 동네에서 거리·선호만 바꿔 다시 만들 때는 길 정보를 다시 받지 않아 빠릅니다.

## 어떻게 만드나요?
1. [Overpass API](https://overpass-api.de)로 집 주변(목표 거리 ÷ 3 + 400m 반경)의 OpenStreetMap 길·공원·하천 데이터를 받습니다.
2. 걸을 수 없는 길(고속도로, 자동차전용도로, 사유지 등)을 빼고 길 그래프를 만듭니다.
3. 선호 설정에 따라 길마다 비용 배수를 매깁니다. (선호 0.6~0.8배, 회피 1.5~8배)
4. 집을 지나는 원 위에 경유지 2~3개를 놓고 A* 로 "집 → 경유지들 → 집" 을 잇습니다.
   이미 지나온 길은 비용을 올려 되도록 다른 길로 돌아오게 합니다.
5. 실제 길이를 재서 원의 반지름을 비율로 보정하는 과정을 반복해 **목표 거리 ±3% 이내**(대부분 ±1%)로 맞춥니다.
6. 8개 방향으로 만들어 보고, 선호 길 비중·반복 구간·거리 오차로 점수를 매겨 서로 다른 코스 3개를 고릅니다.

## 개발
```bash
node --test running-course/test/*.test.js   # 코스 생성 알고리즘 테스트 (가상 동네 지도 사용)
```
```
running-course/
  index.html   화면
  style.css    디자인 (다크 모드 지원)
  app.js       지도(Leaflet), 주소 검색, 설정 저장, 결과 표시
  course.js    코스 생성 엔진 (그래프, 선호 비용, A*, 순환 코스, GPX) — Node 에서도 동작
  test/        테스트
```

## 배포
`running-course/` 가 바뀌어 push 되면 [워크플로](../.github/workflows/running-course-pages.yml)가
테스트를 돌린 뒤 `gh-pages` 브랜치에 올리고, GitHub Pages 가 그 브랜치를 사이트로 보여줍니다.
(저장소 Settings → Pages → Source: "Deploy from a branch", Branch: `gh-pages` / `/ (root)`)
