기능설정 템플릿 저장·적용

파일 메뉴: 지금 설정을 템플릿으로 저장(이름 입력, 음악 포함 여부 선택) / 템플릿 적용(목록, 템플릿 폴더 열기). 클립·작은 화면·자막 내용·제목 내용·출력 경로는 빼고 저장, 적용해도 지금 클립·자막 내용은 그대로. 실행 취소로 되돌릴 수 있음. 저장 위치: 데이터 폴더/templates

결과 완료 · 화면 테스트로 저장→적용→실행 취소 확인
기능릴스 가림 영역 피하기 + 표시

기본 자막 위치(아래 8%)와 오른쪽 아래 작은 화면이 릴스 설명·버튼에 가려지는 문제. 세로 영상(높이/너비 ≥ 1.6)이면 자막·제목·작은 화면 여백을 위 12%/아래 22%/오른쪽 13% 이상으로(이미 더 크면 그대로). 미리보기 전용 "가림 영역 표시"로 붉게 확인. 비교 이미지로 확인. 남은 점: 아래쪽 작은 화면과 아래 자막이 겹칠 수 있음(위치 설정으로 조정)

기능폴더 통째로 추가 + 찍은 날짜순

📁 폴더: 하위 폴더까지 영상·사진을 찾아(숨김 파일·.AAE 등 제외) 찍은 시각순으로 추가, 파일이 많으면 진행 창(그만 버튼). 📅 날짜순: 전체 다시 정렬. 찍은 시각은 아이폰 creationdate(현지 시간대 포함) → creation_time → 사진 EXIF(시간대 있으면 반영) → 파일 수정 시각 순. 목록에 날짜 표시

결과 완료 · 도쿄→사진→오사카→교토 순서 확인
기능아이폰 HEIC 사진 지원

HEIC/HEIF 사진을 추가하면 pillow-heif로 한 번 JPG로 바꿔 두고(EXIF 회전 반영, 크기·수정 시각 기준 재사용) 렌더링·썸네일·작은 화면·장면 저장에 사용. 프로젝트에는 원본 경로 유지. 함께 고침: 목록 썸네일이 세로 사진(EXIF 회전)을 가로로 보여 주던 문제. 설치본에 pillow-heif 포함

결과 완료 · 세로 HEIC 렌더링 방향 확인
버그 수정소리가 하나도 없는 영상 내보내기 실패

무음 영상·사진만 있고 음악이 없으면 음량 자동 맞춤(loudnorm)이 완전한 무음에서 NaN을 내서 내보내기가 실패 → 소리가 없을 땐 음량 맞춤을 건너뜀. HDR 테스트 중 발견

결과 수정
버그 수정아이폰 HDR 영상이 회색으로 바램

아이폰 기본 HDR(HLG, BT.2020 10비트 HEVC) 영상을 넣으면 색이 크게 바램(채도 247→94). 영상마다 전달 특성을 확인해서 HDR이면 zscale+tonemap(mobius)으로 일반 색으로 변환 — 클립·작은 화면·장면 이미지 저장 모두. 채도 211로 회복, 속도 부담 약 12%

결과 수정 · 비교 이미지 확인
계획6차 로드맵: 일본 여행 릴스용으로 재정렬

사용 목적(일본 여행 영상 모음 → 릴스, 다른 여행에도 재사용)에 맞춰 우선순위 재설정: 30 아이폰 HDR 색, 31 HEIC 사진, 32 폴더 추가·날짜순, 33 릴스 안전 영역, 34 설정 템플릿, 35 음악 없이 내보내기

결과 계획
기능자막 등장 효과

자막 "등장 효과": 없음/스르륵 나타나기/톡 튀어나오기(70%→112%→100%, 0.18초). ffmpeg가 SRT를 읽을 때 효과 태그를 지워 버려서, SRT를 읽을 때와 똑같은 머리말(384×288)의 ASS 파일로 만들어 입힘 → 효과가 끝난 뒤 화면은 효과 없을 때와 같음(아래·가운데·위 모두 비교). 자막 트랙 방식에선 꺼짐
