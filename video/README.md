# 🎬 ReelCut 영상 편집기

여러 영상을 이어붙이고, 자막을 자동으로 만들고, 노래 박자에 맞춰 컷을 바꾸고,
화면 속 화면(오른쪽 아래 작은 영상)을 넣을 수 있는 **Windows 데스크톱 영상 편집기**입니다.
(Python + PySide6 + FFmpeg + faster-whisper)

## 기능

### 1. 🎬 클립 이어붙이기
- 영상·사진을 추가하고 (창에 끌어다 놓기도 됨) 목록을 끌어서 순서 변경
- 클립마다 **시작/끝 자르기** — 미리보기를 보다가 "현재 위치" 버튼으로 바로 지정
- 해상도·비율·프레임레이트가 달라도 자동으로 맞춤 (남는 부분은 검은 여백)
- 소리가 없는 영상, 사진(기본 3초)도 섞어 쓸 수 있음

### 2. 🎵 노래 등록 + 비트에 맞춰 잘라 이어붙이기
- 음악(mp3, wav, m4a, flac …)을 등록하면 **템포(BPM)와 비트 위치를 자동 분석**
- "사용하기"를 켜면 클립을 **1·2·4·8·16비트마다 잘라서** 비트 순간에 화면이 바뀌는 영상을 만듦
  - 컷 위치는 프레임 단위로 맞춰서 길어져도 박자가 밀리지 않음
- 클립 고르는 방식: **차례대로** / **골고루**(각 클립 전체에서 고르게) / **무작위**(다시 섞기)
- 영상 길이: 음악 길이만큼 또는 클립 길이만큼, 최대 길이 제한
- 분석이 틀리면: ×2 · ÷2 버튼, BPM 직접 입력, 비트 위치 미세 조정
- 음악 시작 위치, 음악/원본 소리 크기, 끝 페이드아웃 조절
- 비트 맞춤을 끄면 음악은 **배경음**으로만 깔림

### 3. 💬 자동 자막
- [faster-whisper](https://github.com/SYSTRAN/faster-whisper)(OpenAI Whisper) 음성 인식으로 자막 자동 생성
- 인식할 소리: **영상 속 말소리** 또는 **등록한 음악의 가사**
- 모델 선택 (tiny ~ large-v3), 언어 선택 (한국어·영어·일본어·중국어·자동)
- 표에서 시간·내용을 바로 고치기, 줄 추가/삭제, **SRT 불러오기/저장**
- **영상에 입히기**(어디서나 보임) 또는 **자막 트랙으로 넣기**(플레이어에서 켜고 끄기)
- 글꼴·크기·외곽선·아래 여백 설정

> 처음 자동 자막을 만들 때 모델을 인터넷에서 내려받아요 (small 약 500MB). 이후에는 오프라인으로 동작합니다.

### 4. 🖼 화면 속 화면 (PiP)
- 완성 영상의 **오른쪽 아래(기본)** 에 다른 영상을 작게 겹쳐 넣기 — 리액션 캠, 해설 화면, 로고 등
- 위치: 오른쪽 아래 / 오른쪽 위 / 왼쪽 아래 / 왼쪽 위 / 가운데 / 직접 지정
- 크기(화면 너비의 5~100%), 나타나는 시점, 보이는 시간, 원본 시작 위치
- 테두리 두께·색, 작은 화면의 소리 크기 (기본 음소거)
- 여러 개 겹치기 가능, 사진(로고)도 가능

### 내보내기
- 가로 1080p / 720p / 4K, **세로 쇼츠·릴스(1080×1920)**, 정사각형
- 24 / 25 / 30 / 60 fps, 화질 3단계, H.264 + AAC **MP4**
- **미리보기 만들기**: 저화질로 빠르게 만들어 바로 재생
- 진행률 표시, 취소 가능
- 프로젝트 저장/열기 (`.reelcut.json`)

## 설치 (빌드된 exe 받기)
1. GitHub 저장소 → **Actions** 탭 → "영상 편집기 빌드" 최신 실행 선택
2. 아래 **Artifacts** 에서 `ReelCut-win-x64` 다운로드 → 압축 해제
3. 폴더 안의 `ReelCut.exe` 실행 (FFmpeg 포함, Python 설치 불필요)

> 서명되지 않은 exe라 처음 실행 시 SmartScreen 경고가 뜰 수 있어요 → "추가 정보" → "실행".

## 소스에서 실행
```bash
cd video
pip install -r requirements.txt
python run_reelcut.py
```
FFmpeg가 필요해요. `video/ffmpeg/` 폴더에 `ffmpeg(.exe)`, `ffprobe(.exe)`를 넣거나 PATH에 추가하세요.

## 테스트
```bash
cd video
pip install numpy pytest
python -m pytest -q tests
```
FFmpeg가 설치돼 있으면 실제 영상을 만들어 보는 통합 테스트도 함께 실행됩니다.

## 구조
| 파일 | 내용 |
|---|---|
| `reelcut/project.py` | 프로젝트 데이터 (클립, 음악, 비트 맞춤, PiP, 자막, 내보내기 설정) |
| `reelcut/beats.py` | 템포·비트 감지 (mel 스펙트럼 변화량 → 자기상관 템포 → 동적 계획법 비트 추적) |
| `reelcut/timeline.py` | 클립 → 렌더링 조각 (이어붙이기 / 비트 맞춤 컷 계획) |
| `reelcut/render.py` | FFmpeg 2단계 렌더링 (조각 규격화 → 이어붙이기 + PiP + 자막 + 음악 믹스) |
| `reelcut/subtitles.py` | SRT 읽기/쓰기, Whisper 자동 자막 |
| `reelcut/ffmpeg.py` | FFmpeg 찾기, 미디어 정보, 진행률 읽기·취소 |
| `reelcut/gui/` | PySide6 화면 |
