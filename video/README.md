# 🎬 ReelCut 영상 편집기

여러 영상을 이어붙이고, 자막을 자동으로 만들고, 노래 박자에 맞춰 컷을 바꾸고,
화면 속 화면(오른쪽 아래 작은 영상)을 넣을 수 있는 **Windows 데스크톱 영상 편집기**입니다.
(Python + PySide6 + FFmpeg + faster-whisper)

## 기능

### 1. 🎬 클립 이어붙이기
- 영상·사진을 추가하고 (창에 끌어다 놓기도 됨) 목록을 끌어서 순서 변경
- **📁 폴더 통째로 추가**(하위 폴더 포함) → 찍은 날짜순으로 자동 정렬, **📅 날짜순** 버튼으로 언제든 다시 정렬 (아이폰 현지 시각·사진 EXIF 날짜 사용)
- 클립마다 **시작/끝 자르기** — 미리보기를 보다가 "현재 위치" 버튼으로 바로 지정
- 클립마다 **속도**(0.25~4배, 소리 음높이 유지)와 **소리 크기·음소거**
- 해상도·비율·프레임레이트가 달라도 자동으로 맞춤 (남는 부분은 검은 여백)
- **아이폰·갤럭시 HDR 영상**(HLG/HDR10)은 자동으로 일반 색으로 바꿔서 회색으로 바래 보이지 않게 함
- 소리가 없는 영상, 사진(기본 3초)도 섞어 쓸 수 있음 — **아이폰 HEIC 사진**도 그대로 (세로로 찍은 사진은 세로로)
- 사진은 **천천히 확대·축소·좌우 이동**(켄 번즈 효과) — 기본은 사진마다 번갈아, 클립별로 고르거나 끌 수 있음

### 2. 🎵 노래 등록 + 비트에 맞춰 잘라 이어붙이기
- **유튜브 링크를 붙여넣고 "mp3로 받기"** → `내 음악\ReelCut` 폴더에 mp3로 저장되고 바로 등록 ([yt-dlp](https://github.com/yt-dlp/yt-dlp) 사용)
  - 갖고 있는 음악 파일을 고르거나 창에 끌어다 놓아도 됨
- **파형 게이지에서 몇 초부터 쓸지 고르기** — 클릭/드래그로 시작 위치 지정, 주황색이 실제로 쓰이는 구간
  - "▶ 시작 위치부터 듣기"(또는 파형 더블클릭·스페이스)로 바로 미리듣기, ←/→ 0.1초 (Shift: 1초) 미세 조정
- 음악(mp3, wav, m4a, flac …)을 등록하면 **템포(BPM)와 비트 위치를 자동 분석**
- "사용하기"를 켜면 클립을 **1·2·4·8·16비트마다 잘라서** 비트 순간에 화면이 바뀌는 영상을 만듦
  - 컷 위치는 프레임 단위로 맞춰서 길어져도 박자가 밀리지 않음
- **컷 리듬**: 일정하게 / 센 비트(강박)에서만 / 신나는 부분(후렴)은 빠르게·조용한 부분은 느리게
- 클립 고르는 방식: **파일 번갈아**(컷마다 1→2→3→1…, 기본) / **파일별로 몰아서**(1번 파일 다 쓰고 2번…) / **무작위**(같은 파일 연속 없음, 다시 섞기) / **이어서**(예전 방식: 파일을 끊김 없이 이어 자름)
  - 이어서를 뺀 나머지는 같은 파일 안에서 처음~끝을 고르게 건너뛰며 사용해서 컷마다 장면이 바뀜
- 자르는 기준: **음악 비트마다** 또는 **일정한 초마다** (예: 2.5초마다 — 음악 없어도 됨)
- 영상 길이: 음악 길이만큼 / 클립 길이만큼 / **클립 개수 × 컷 길이** (클립마다 딱 한 번씩, 노래도 거기서 끝), 최대 길이 제한
  - 예: 길이가 제각각인 영상 8개 × 2.5초 → 20초 영상, 음악도 20초에서 페이드아웃
- 분석이 틀리면: ×2 · ÷2 버튼, BPM 직접 입력, 비트 위치 미세 조정
- 음악 시작 위치, 음악/원본 소리 크기, 끝 페이드아웃 조절
- **말할 때 음악 줄이기**(덕킹): 영상 원본·작은 화면에서 말소리가 나오면 음악을 자동으로 줄였다가 다시 키움 (약하게 ≈ 9dB / 보통 ≈ 13dB / 세게 ≈ 18dB)
- 비트 맞춤을 끄면 음악은 **배경음**으로만 깔림

> **노래는 어디서 구하나요?** 영상을 올릴 거라면 저작권 걱정 없는 곳을 추천해요:
> [YouTube 오디오 보관함](https://studio.youtube.com)(유튜브 스튜디오 → 오디오 보관함),
> [Pixabay Music](https://pixabay.com/music/), [공유마당](https://gongu.copyright.or.kr/), [FreeMusicArchive](https://freemusicarchive.org/).
> 이런 곡의 유튜브 링크나 다운로드 파일을 그대로 쓰면 돼요. 일반 가요·팝은 업로드 시 저작권 차단이나 수익 제한이 걸릴 수 있어요.

### 3. 💬 자동 자막
- [faster-whisper](https://github.com/SYSTRAN/faster-whisper)(OpenAI Whisper) 음성 인식으로 자막 자동 생성
- 인식할 소리: **영상 속 말소리** 또는 **등록한 음악의 가사**
- 모델 선택 (tiny ~ large-v3), 언어 선택 (한국어·영어·일본어·중국어·자동)
- 표에서 시간·내용을 바로 고치기, 줄 추가/삭제, **SRT 불러오기/저장**
- **영상에 입히기**(어디서나 보임) 또는 **자막 트랙으로 넣기**(플레이어에서 켜고 끄기)
- **자막 글꼴 지정**: 컴퓨터에 설치된 글꼴 목록에서 고르거나, **글꼴 파일(.ttf/.otf)을 설치 없이 바로 불러오기**
  (예: 눈누·네이버 나눔 등 무료 글꼴을 받아서 파일만 선택)
- 크기, 굵게, 글자색, 외곽선 색·두께, 배경 상자, 위치(아래/가운데/위)·여백 — 화면에서 바로 미리보기

> 처음 자동 자막을 만들 때 모델을 인터넷에서 내려받아요 (small 약 500MB). 이후에는 오프라인으로 동작합니다.
- **등장 효과**: 스르륵 나타나기 / 톡 튀어나오기 (영상에 입힐 때)

### 4. 🖼 화면 속 화면 (PiP)
- 완성 영상의 **오른쪽 아래(기본)** 에 다른 영상을 작게 겹쳐 넣기 — 리액션 캠, 해설 화면, 로고 등
- 위치: 오른쪽 아래 / 오른쪽 위 / 왼쪽 아래 / 왼쪽 위 / 가운데 / 직접 지정
- 크기(화면 너비의 5~100%), 나타나는 시점, 보이는 시간, 원본 시작 위치
- 테두리 두께·색, 작은 화면의 소리 크기 (기본 음소거)
- 여러 개 겹치기 가능, 사진(로고)도 가능

### 5. 🔤 제목
- 영상 위에 큰 제목 글자를 원하는 시간에 (서서히 나타났다 사라짐), 여러 개 가능
- 글꼴(설치된 글꼴 또는 파일), 크기, 굵게, 글자·외곽선 색, 위치(가운데/위/아래)

### 비트 컷 전환 효과
- 비트마다 화면이 바뀔 때: 번쩍(흰 플래시) / 줌 펀치 / 검은 깜빡임

### 내보내기
- **음악 넣기** 끄기: 비트 컷은 그대로, 음악 소리만 빼고 내보냄 → 인스타 앱 음악 기능으로 같은 노래를 붙이면 저작권 음소거 걱정이 적음 (완료 창에 맞춰야 할 노래 시작 위치 안내)
- **릴스 가림 영역 피하기**(기본 켬): 세로 영상이면 자막·제목·작은 화면을 릴스 화면의 위쪽 메뉴·아래쪽 설명·오른쪽 버튼이 가리는 곳(대략 위 12%, 아래 22%, 오른쪽 13%) 밖으로 옮김. **미리보기에 가림 영역 표시**를 켜면 가려지는 곳이 붉게 보임 (내보내기엔 안 들어감)
- **장면을 이미지로 저장**(미리보기 옆 🖼): 지금 보이는 장면을 내보내기 크기·화면 맞추기·색감 그대로 JPG/PNG로 (유튜브 썸네일용, 자막·제목 없이)
- **여러 비율로 한 번에**(📐 버튼, Ctrl+Shift+E): 유튜브 가로·릴스 세로·정사각형·인스타 피드 중 고른 만큼 `이름_유튜브.mp4`, `이름_릴스.mp4` … 로 만듦
- **그래픽카드로 빠르게**: NVIDIA(NVENC)·Intel(QSV)·AMD(AMF) 인코더가 있으면 최종 인코딩에 사용, 실패하면 자동으로 CPU로 다시 만듦
- **색감 필터**: 따뜻하게 · 차갑게 · 선명하게 · 빈티지 · 흑백 (자막·제목 색은 그대로)
- 시작·끝 페이드 (검은 화면에서 나타나고 사라짐, 소리도 함께)
- 자동 저장: 저장하지 않고 꺼져도 다음 실행 때 복구
- 파일을 옮겨도 폴더를 고르면 같은 이름으로 다시 연결
- **화면 비율 버튼**: 유튜브(가로 16:9) / **릴스·쇼츠·틱톡(세로 9:16)** / 정사각형(1:1) / 인스타 피드(4:5)
  - 해상도 720p / 1080p / 4K 선택
  - 비율이 다른 영상(예: 가로 영상을 세로 릴스로): **흐린 배경으로 채우기**(기본) / 잘라서 꽉 채우기 / 검은 여백
- 24 / 25 / 30 / 60 fps, 화질 3단계, H.264 + AAC **MP4**
- **미리보기 만들기**: 저화질로 빠르게 만들어 바로 재생
- **음량 자동 맞춤**: 최종 소리를 유튜브·릴스 권장 크기(-14 LUFS)로 (기본 켬)
- 진행률에 남은 시간 표시, 렌더링은 여러 조각을 동시에 처리해서 빠름
- **🔊 소리 출력 장치 선택** (재생 바 오른쪽): '시스템 기본'은 헤드폰을 꽂거나 빼면 자동으로 따라가고, 특정 장치를 고를 수도 있음 · ↻ 다시 찾기
- 진행률 표시, 취소 가능
- 프로젝트 저장/열기 (`.reelcut.json`)

### 📋 설정 템플릿 (다음 여행에 그대로)
- 파일 > **지금 설정을 템플릿으로 저장**: 컷 방식·자막 모양·등장 효과·제목 모양·색감·화면 비율·내보내기 설정을 저장 (클립·자막 내용·제목 내용은 빼고, 음악은 넣을지 선택)
- 파일 > **템플릿 적용**: 새 여행 클립을 넣고 고르면 같은 스타일로 바로 완성

## 설치 (빌드된 exe 받기)
1. GitHub 저장소 → **Actions** 탭 → "영상 편집기 빌드" 최신 실행 선택
2. 아래 **Artifacts** 에서 `ReelCut-win-x64` 다운로드 → 압축 해제
3. 폴더 안의 `ReelCut.exe` 실행 (FFmpeg·Deno 포함, Python 설치 불필요)

> 서명되지 않은 exe라 처음 실행 시 SmartScreen 경고가 뜰 수 있어요 → "추가 정보" → "실행".

## 소스에서 실행
```bash
cd video
pip install -r requirements.txt
python run_reelcut.py
```
FFmpeg가 필요해요. `video/ffmpeg/` 폴더에 `ffmpeg(.exe)`, `ffprobe(.exe)`를 넣거나 PATH에 추가하세요.

## 테스트
```bash
cd video
pip install numpy pytest
python -m pytest -q tests
```
FFmpeg가 설치돼 있으면 실제 영상을 만들어 보는 통합 테스트도 함께 실행됩니다.

|---|---|
| `reelcut/project.py` | 프로젝트 데이터 (클립, 음악, 비트 맞춤, PiP, 자막, 내보내기 설정) |
