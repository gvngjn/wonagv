## 우선순위 기준 (위가 먼저)

1. 작업이 날아가거나 결과물이 잘못 나오는 문제 (데이터 손실·오동작)
2. 사용자가 직접 겪고 알려준 불편
3. 매번 쓰는 흐름(편집 → 미리보기 → 내보내기)의 체감 속도·편의
4. 결과물 완성도를 높이는 새 기능
