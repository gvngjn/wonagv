# 🚦 초록불 알리미

휴대폰을 대시보드에 거치해 두면, **빨간불에서 기다리다 초록불로 바뀌는 순간** 차임벨 + "초록불입니다" 음성으로 알려 주는 웹앱입니다.
앱 설치 없이 iPhone(Safari)·Android(Chrome) 브라우저에서 바로 동작합니다.

> ⚠️ 운전 보조용입니다. 출발 전 반드시 신호·전방·보행자를 직접 확인하세요.

## 사용법
1. 휴대폰을 앞유리/대시보드 거치대에 놓고 **후면 카메라가 신호등을 향하게** 합니다 (가로 거치 권장).
2. 페이지를 열고 **카메라 켜고 시작** → 카메라 권한 허용.
3. 화면을 손가락으로 드래그해 **신호등이 보이는 부분만 박스로** 지정합니다.
   앞차 브레이크등·간판이 박스에 들어가지 않게 위쪽으로 좁게 잡을수록 정확합니다.
4. 정차 중 박스 테두리가 **빨간색(빨간불 대기 중)** 이 되면 준비 완료. 초록불이 켜지면 소리가 납니다.

`🔊 소리` 버튼으로 미리 소리를 확인하세요 (iPhone은 무음 스위치를 꺼야 들립니다).
⚙︎ 에서 감도, 음성 안내, 감지된 색 표시를 바꿀 수 있습니다.

## 오작동을 막는 규칙
- 빨간불이 **1.5초 이상 계속** 보여야 "신호 대기"로 인정 → 달리면서 스쳐 본 빨간불은 무시
- 초록불이 **0.4초 이상 계속** 보여야 알림 → 반사·깜빡임 무시
- 빨간불이 사라진 뒤 **4초 안에** 초록불이 떠야 함 → 차가 움직여 신호등이 화면에서 벗어나면 대기 해제
- 한 번 알리면 **15초간** 다시 울리지 않음
- 초록불만 보이는 경우(이미 초록인 교차로 통과)는 울리지 않음

## 열기 (https 필요)
카메라는 https 주소에서만 켜집니다. 이 저장소에는 GitHub Pages 배포 워크플로가 들어 있어요.
1. GitHub 저장소 → **Settings → Pages → Build and deployment → Source: GitHub Actions**
2. `green-light/` 변경이 push되면 "초록불 알리미 배포" 워크플로가 실행되고
   `https://<사용자명>.github.io/<저장소>/` 주소가 생깁니다. 휴대폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

> 비공개 저장소의 Pages는 유료 플랜에서만 지원됩니다. 이 경우 `green-light/` 폴더를 Netlify Drop 등에 올려도 됩니다.

PC에서 테스트: `cd green-light && python3 -m http.server` → `http://localhost:8000` (localhost는 http도 허용)

## 구조
| 파일 | 내용 |
|---|---|
| `detector.js` | 픽셀 색 판별(HSV), 빨강/초록 비율 계산, 빨간불→초록불 상태 머신 |
| `index.html` | 카메라 화면, 감지 영역 지정, 소리·음성·진동·화면 꺼짐 방지 |
| `detector.test.js` | 테스트 — `node --test green-light/detector.test.js` |

## 한계

- 화살표 신호(좌회전)와 직진 신호를 구분하지 못합니다.
- 화면이 켜져 있어야 동작합니다 (화면 꺼짐 방지 기능 사용).
