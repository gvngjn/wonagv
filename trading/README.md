# 📈 trendbot — 큰 추세만 잡는 저빈도 자동매매

수수료와 세금이 덜 나가도록 **큰 상승 추세에만 올라타고, 자주 사고팔지 않는** 주식 자동매매 프로그램입니다.
지금은 **모의매매·백테스트와 한국투자증권 모의투자 계좌 연결**까지 있고, 실전 계좌로 주문을 내는 코드는 없습니다.

## 구조

```
일봉 데이터 ─▶ 신호(전략) ─▶ 리스크(비중·손절·필터) ─▶ 브로커(모의매매) ─▶ 결과 보고
 data.py       strategy.py     risk.py / costs.py        broker.py           report.py
                         └──────── engine.py 가 하루 단위로 묶어서 실행 ────────┘
```

| 파일 | 역할 |
|---|---|
| `data.py` | CSV 일봉 읽기 (`date,open,high,low,close,volume`, 파일명 = 종목코드), 시험용 가상 데이터 |
| `strategy.py` | 55일 최고가 돌파 + 200일선 위·상승 중일 때만 진입, 20일 최저가 이탈 또는 손절가 이탈 시 청산 |
| `risk.py` | 손절폭(2×ATR) 기준으로 한 번에 총자산 1%만 잃도록 수량 계산, 종목당 25%·최대 5종목 |
| `config.py` | 설정 파일(`trendbot.toml`) 읽기. 수수료·세금은 코드가 아니라 **설정 파일에서만** 관리 |
| `costs.py` | 수수료·매도 세금·슬리피지 계산 (값은 설정 파일에서) |
| `orders.py` | 지정가 계산 (호가 단위 맞춤). **시장가 주문은 쓰지 않음** |
| `schedule.py` | 실행 시간대·주말·휴장일 확인 |
| `cache.py` | 일봉 디스크 캐시. 받은 날짜는 다시 요청하지 않음 |
| `broker.py` | `Broker` 인터페이스와 `PaperBroker`(모의 계좌). 증권사 연결은 이 인터페이스를 구현해 붙입니다 |
| `planner.py` | 하루치 판단(청산·진입 주문 결정). 백테스트와 모의투자 실행이 같은 함수를 씀 |
| `engine.py` | 장 마감 후 종가로 판단 → **다음 날 지정가**로 체결 (시가가 유리하면 시가, 장중에 닿으면 지정가, 아니면 미체결) |
| `kis.py` | 한국투자증권 Open API **모의투자 서버 전용** 클라이언트 (일봉·잔고·지정가 주문) |
| `live.py` | 모의투자 계좌로 하루 한 번 실행. 손절가·청산일은 상태 파일에 저장 |

### 수수료를 아끼는 장치
- **일봉만 사용**: 하루 한 번만 판단하므로 잦은 매매가 구조적으로 불가능
- **긴 돌파 기간(55일)과 추세 필터(200일선)**: 작은 흔들림에는 진입하지 않음
- **움직임 필터**: 손절폭이 왕복 비용의 10배보다 작은 종목은 건너뜀
- **최소 주문금액(100만 원)**: 수수료 비중이 커지는 작은 주문 차단
- **재진입 대기(10거래일)**: 청산 직후 같은 종목을 바로 다시 사지 않음

## 설정 파일

`trendbot.example.toml` 을 `trendbot.toml` 로 복사해서 고칩니다. 찾는 순서는 `--config` → `./trendbot.toml` → `~/.trendbot/config.toml` 입니다.

- `[costs]` 수수료·세금: **항목이 하나라도 빠지면 실행하지 않습니다** (조용히 기본값으로 돌지 않게)
- `[order]` 지정가 여유: 매수는 어제 종가 +1%, 매도는 -2%를 호가 단위로 맞춰 냅니다
- `[risk]`, `[strategy]` 비중·손절·돌파 기간
- `[schedule]` 실행 시간대와 휴장일 목록 (매년 갱신)
- `[universe]` 감시 종목, `[paths]` 캐시·상태 파일 위치
- 오타 난 항목 이름은 오류로 알려 줍니다

백테스트(`demo`, `backtest`)는 `trendbot.toml` 이 없으면 예시 파일로 돌지만, 모의투자 실행(`kis-run`, `fetch`)은 내 설정 파일이 있어야 돕니다.

## 실행 (Python 3.11 이상, 추가 설치 없음)

```bash
cd trading
python -m trendbot demo                    # 가상 데이터로 백테스트
python -m trendbot backtest --data ./data  # 내 CSV 일봉으로 백테스트
python -m unittest discover -s tests -t .  # 테스트
```

## 한국투자증권 모의투자로 돌리기

1. [KIS Developers](https://apiportal.koreainvestment.com)에서 **모의투자 계좌**를 신청하고, 모의투자용 앱키·앱시크릿을 발급받습니다.
2. 환경변수를 설정합니다 (코드나 저장소에 키를 적지 마세요).
   ```bash
   export KIS_APP_KEY=...        # 모의투자용 앱키
   export KIS_APP_SECRET=...
   export KIS_ACCOUNT=50012345-01
   ```
3. `trendbot.toml` 을 만들고 수수료·세금·종목을 내 기준으로 고칩니다.
4. 실제 일봉으로 먼저 백테스트해 봅니다.
   ```bash
   python -m trendbot fetch --out data      # 설정 파일의 종목 일봉을 CSV로
   python -m trendbot backtest --data data
   ```
5. **평일 08:30~08:59**(설정의 `[schedule]`)에 하루 한 번 실행합니다. 어제 종가로 판단하고 지정가 주문을 냅니다.
   ```bash
   python -m trendbot kis-run              # 미리보기만
   python -m trendbot kis-run --submit     # 모의투자 계좌로 지정가 주문
   ```
   - 실행 시간대가 아니거나 주말·휴장일이면 **API를 한 번도 부르지 않고** 바로 끝납니다. 미리보기만 `--ignore-hours` 로 시간과 상관없이 볼 수 있습니다.
   - 보유 종목은 종목 목록에 없어도 자동으로 점검합니다.
   - 일봉은 `~/.trendbot/cache` 에 저장해 두고 새 날짜만 받습니다. 액면분할 등으로 과거 가격이 바뀌면 그 종목만 처음부터 다시 받습니다.
   - 0원 가격이 섞인 봉은 버리고, 최신 봉이 없는 종목(거래정지 등)은 그날 판단하지 않습니다. 0원 때문에 보유 종목이 가짜 손절로 팔리지 않게 하려는 장치입니다.
   - 매도 지정가가 시초가 급락으로 체결되지 않으면 다음 날 다시 판단해서 냅니다.
   - 손절가·청산일은 `~/.trendbot/state.json`에 저장됩니다. 지우면 손절가 기록이 사라지니 주의하세요.
   - 토큰은 `~/.trendbot/kis_mock_token.json`에 저장해 하루 동안 재사용합니다.

### 안전장치
- 접속 주소는 모의투자 서버(`openapivts...:29443`) 하나뿐이고, 거래 ID도 모의투자용(`VTTC...`)만 들어 있습니다. 테스트가 실전 주소·실전 거래 ID가 코드에 없는지 확인합니다.
- `--submit` 없이 실행하면 주문을 보내지 않고 미리보기만 합니다.
- 주문은 지정가(`ORD_DVSN=00`)만 냅니다. 시장가 주문 함수 자체가 없고, 테스트가 이를 확인합니다.
