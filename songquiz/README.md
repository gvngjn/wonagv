# 스타1 유즈맵 노래 맞추기

내 플레이리스트로 스타크래프트(리마스터) 노래 맞추기 유즈맵을 만드는 도구예요.
노래 클립이 나오면 플레이어가 **채팅으로 제목을 치고**, 제일 먼저 맞힌 사람이 1점을 받아요.

## 필요한 것

- [euddraft](https://cafe.naver.com/edac) 0.11 이상 (Windows)
- Python 3.10+
- [yt-dlp](https://github.com/yt-dlp/yt-dlp), [ffmpeg](https://ffmpeg.org) (PATH 에 추가)
- 베이스 맵 `.scx` 1개 (ScmDraft 등으로 만들기)

## 1. 베이스 맵 준비

1. 플레이어 1~8 중 쓸 슬롯을 Human 으로 설정
2. **플레이어마다 Terran Command Center 를 1개씩** 놓기
   (정답 신호용. 맵 구석에 두고 무적으로 해 두면 좋아요. 다른 건물을 쓰려면 `--signal-unit`)
3. 리더보드에 쓸 점수는 맵이 자동으로 Custom 점수에 더해요.
   필요하면 맵 트리거에 `Leader Board Points (Custom, "점수")` 를 추가하세요.

## 2. 플레이리스트 가져오기

```bash
# 유튜브 플레이리스트
python songquiz.py import "https://www.youtube.com/playlist?list=..."

# 스포티파이: https://exportify.net 에서 플레이리스트를 CSV 로 내보낸 뒤
python songquiz.py import my_spotify.csv
```

`playlist.csv` 가 생겨요. 엑셀/메모장으로 열어서 확인해 주세요.

| 칸 | 설명 |
|---|---|
| `title` | 정답 (곡 제목). 띄어쓰기 없앤 것, 대/소문자 버전도 자동으로 인정 |
| `artist` | 가수. 힌트로 나와요 |
| `answers` | 추가로 인정할 정답, `;` 로 구분. 예: `슈퍼샤이;super shy` |
| `url` | 유튜브 주소. 비우면 `가수 제목` 으로 유튜브 검색 |
| `start` | 클립 시작 지점(초). 후렴 시작 위치를 넣으면 좋아요. 비우면 `--start` 값 |

스포티파이 곡은 음원을 직접 받을 수 없어서 유튜브에서 같은 곡을 찾아 받아요.
엉뚱한 영상이 걸리면 `url` 칸에 직접 주소를 넣어 주세요.

## 3. 클립 만들기

```bash
python songquiz.py build --map 베이스맵.scx
```

- 곡을 받아 20초 클립(ogg, 모노)으로 자르고 `build/` 에 저장해요. 받은 파일은 캐시돼요.
- 출제 순서는 빌드할 때마다 섞여요 (`--no-shuffle` 로 끄기).
- `songquiz.edd` 가 만들어져요.

자주 쓰는 옵션: `--seconds 15` (클립 길이), `--hint 8` (가수 힌트 시점),
`--limit 30` (곡 수 제한), `--force` (클립 다시 자르기).

## 4. 맵 컴파일

`songquiz.edd` 를 euddraft 로 열면(드래그 앤 드롭) `베이스맵_songquiz.scx` 가 나와요.

## 게임 진행

1. 시작 5초 뒤 첫 곡 재생
2. 채팅으로 제목 입력 → 맞히면 "○○님 정답!" 과 점수 표시
3. 10초 뒤 가수 힌트, 클립이 끝나면 시간 초과 → 정답 공개
4. 다음 곡 (노래는 중간에 끌 수 없어서 클립이 끝난 뒤 넘어가요)
5. 마지막 곡 뒤 우승자 발표

## 동작 원리

- 채팅 인식은 euddraft 기본 플러그인 `[chatEvent]` 를 써요. 이 플러그인은
  **채팅 친 사람 PC 에서만** 인식해서, 그대로 점수를 주면 멀티에서 튕겨요(디싱크).
- 그래서 정답을 친 사람의 PC 가 자기 커맨드 센터의 랠리 포인트를
  `(64 + 라운드 번호, 64)` 로 찍는 게임 명령을 보내고, 모든 PC 가 그 랠리 좌표를 보고
  같은 프레임에 정답자를 판정해요. (`map/quiz.py`)
- 그래서 정답을 맞히는 순간 그 사람의 유닛 선택이 커맨드 센터로 바뀌어요.

## 알아 둘 점

- 한 줄 채팅은 78바이트(한글 약 26자)까지만 인식돼요. 더 긴 제목은 `answers` 에 줄임말을 넣으세요.
- 맵 용량: 20초 클립 1곡이 약 150~250KB. 곡이 많으면 `--seconds` 를 줄이세요.
- 같은 프레임에 두 명이 맞히면 플레이어 번호가 앞선 사람이 점수를 받아요.
- 개인적으로 친구들과 노는 용도로 쓰세요. 음원 저작권이 있는 맵을 공개 배포하면 문제가 될 수 있어요.
